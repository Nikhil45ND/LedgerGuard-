# LedgerGuard-

Dynamic Multi-Tenant Zero-Knowledge Billing Engine

LedgerGuard is a multi-tenant billing platform designed to provide secure tenant isolation, reliable transaction processing, and an idempotent billing ledger.

Project Objectives

- Secure authentication and tenant-based access.
- Dynamic multi-tenant database management.
- Reliable billing and transaction processing.
- Prevention of duplicate billing events.
- Analytics dashboard for billing and usage.
- Cryptographic verification of requests.

Technology Stack

- Frontend: React, TypeScript
- Backend: Node.js, Express.js
- Database: MongoDB, Mongoose
- Cache and Distributed Locks: Redis
- Authentication: JWT
- Cryptography: RSA signatures with SHA-256 (subject to mentor confirmation)

Project Structure

- "client/" — Frontend application
- "server/" — Backend application
- "docs/" — Project documentation
